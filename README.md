# Análisis de Algoritmos

Repositorio del curso de **Análisis de Algoritmos**. Aquí se publican los cinco informes de laboratorio evaluativos, los ejercicios de las sesiones prácticas y los scripts compartidos de medición de tiempos.

## Estructura del repositorio

El repositorio se organiza en las siguientes carpetas:

- **laboratorios/** — Carpeta con los cinco informes de laboratorio evaluativos del semestre. Contiene una subcarpeta por cada laboratorio.
- **ejercicios-clase/** — Código de las sesiones prácticas no evaluativas, incluyendo los ejercicios de Python de la Semana 2.
- **benchmarks/** — Scripts compartidos de medición de tiempos y graficación utilizados en los laboratorios evaluativos.
